## 🎯 What is Ascendra?

> Most enterprises manage strategic quarterly goals through fragmented spreadsheets, static check-ins, and disconnected HR portals, creating invisible execution gaps. 
> 
> **Ascendra** replaces this chaos with a living, automated **Execution Control Plane** inside the browser. It unites employee workflow self-service, manager review terminals, and administrative cycle management under a single glassmorphic cockpit.

---

## 🔥 Key Features

*   🔄 **Dynamic Role Workspaces** — Swap instantly between isolated **Administrator**, **Manager**, and **Employee** panels without page reloads or layout shift (CLS).
*   🩺 **5-Point Compliance Intelligence** — Continuous automated scanners flagging overdue metrics, supervisor workload bottlenecks, shared KPI target conflicts, rework queues, and post-cycle locks.
*   📈 **Executive Observability Cockpit** — Interactive telemetry metrics, risk indicators, progress trend charts (driven by **Chart.js**), and manager effectiveness logs.
*   🌳 **Org Reporting Matrix** — Interactive visual organizational tree highlighting subordinates, execution percentages, and click-to-open target history drawers.
*   💾 **Zero-Infra Sandboxing** — Runs 100% client-side with an auto-seeding engine populating **12 profiles, 60+ goals, and 220+ audit logs** directly inside browser `LocalStorage`.

## 🚀 Quick Start

Get your local sandbox environment up and running in under 60 seconds:

```bash
# 1. Clone the repository
git clone https://github.com/Laukikrathod2007/Ascendra.git
cd Ascendra

# 2. Install development assets
npm install

# 3. Start local hot-reloaded dev server
npm run dev
# Vite server boots at http://localhost:5173/

# 4. Generate local production bundle
npm run build
```

### Deploy to Vercel (Zero Config)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FLaukikrathod2007%2FAscendra)

Vite is auto-detected. Since the routing is state-driven inside the client shell, **no backend redirects or custom `vercel.json` rewrites are required.**
